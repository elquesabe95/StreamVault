Endpoints del Player

GET /embed/movie/{tmdb_id} 🎬 Película

Carga el player embed para una película usando su ID de TMDB.

Parámetros
NombreTipoReq.Descripción
tmdb_idintegerrequeridoID numérico de la película en TMDB
EJEMPLO
<iframe src="https://streamvault-vj0p.onrender.com/embed/movie/272"
  width="100%" height="500" frameborder="0"
  allowfullscreen allow="autoplay; encrypted-media">
</iframe>
GET /embed/tv/{tmdb_id}?season={s}&episode={e} 📺 Series

Carga el player embed para un episodio de serie.

Parámetros
NombreTipoReq.Descripción
tmdb_idintegerrequeridoID de la serie en TMDB
seasonintegerrequeridoNúmero de temporada
episodeintegerrequeridoNúmero de episodio
EJEMPLO
<iframe src="https://streamvault-vj0p.onrender.com/embed/tv/1399?season=1&episode=1"
  width="100%" height="500" frameborder="0"
  allowfullscreen allow="autoplay; encrypted-media">
</iframe>
GET /api/v1/tv/all?page=1&limit=200 📡 Canales TV

Lista todos los canales de TV disponibles con nombre, logo, categoría y URL del stream.

Parámetros
NombreTipoReq.Descripción
pageintegeropcionalPágina (default 1)
limitintegeropcionalResultados por página (default 20)
EJEMPLO
fetch("https://streamvault-vj0p.onrender.com/api/v1/tv/all?page=1&limit=200")
  .then(r => r.json())
  .then(data => console.log(data.results));
// [{name, logo, country, category, url}, ...]
GET /api/v1/tv/all?search={query} 🔍 Buscar TV

Busca canales en vivo consultando múltiples fuentes (TeleOnline + Animux).

Parámetros
NombreTipoReq.Descripción
querystringrequeridoTérmino de búsqueda

  .then(r => r.json())
  .then(data => console.log(data.results));
